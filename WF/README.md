# Plany WF

Każdy semestr ma swój folder: `RRRR-RRRR_zima` albo `RRRR-RRRR_lato`
(np. `2026-2027_zima`). Folder na nowy semestr **tworzy się sam**, gdy WAT
opublikuje plan — jest w nim plik `TUTAJ_WRZUC_PLIK_WF.txt`.

**Jak dodać plan WF:** wejdź w folder semestru na GitHubie →
*Add file → Upload files* → przeciągnij `.xlsx` → *Commit changes*.
Nazwa pliku dowolna. Kalendarz przebuduje się sam w ~2 minuty.

- Poprawiona wersja? Wrzuć ją obok — liczy się zawsze **najnowszy** plik.
- Stare foldery możesz zostawić, nie przeszkadzają nowym semestrom.
- Tylko `.xlsx`. Plik `.xls`/`.ods` zapisz najpierw jako `.xlsx`.

Format pliku (taki, jak daje WF): kolumna A — data, B — kod zajęć,
C — „miejsce - temat”; wiersz bez daty z dniem tygodnia w B i nazwiskiem
w C to nagłówek bloku z prowadzącym.
